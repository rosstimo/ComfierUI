# Examples

This directory is intentionally free of personal workflows and assets. Add only
small redistributable examples containing no credentials, private prompts,
private filenames, or model-site tokens.

- `compose.extra-model-paths.yaml` demonstrates mounting additional model roots
  and the matching ComfyUI config file.
- Configuration templates live under `config/`.
- Backup timer templates live under `systemd/`.

Copy examples to their non-`.example` local names before editing. Local copies
are ignored where appropriate.
